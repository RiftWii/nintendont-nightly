# Nintendont nightly

Daily packages of [Nintendont](https://github.com/FIX94/Nintendont) from its newest
commit: the `loader.dol` its authors commit (the file Nintendont's own
updater installs), with its icon, `meta.xml` and title list, for the [Rift Store](https://github.com/RiftWii/apps),
RiftWii's homebrew store. A new one is made only when upstream has changed,
and each one is a release with its own tag and the exact source it came
from.

These are not official releases. Problems with Nintendont itself belong
upstream: https://github.com/FIX94/Nintendont/issues
